# 패치 파일

이미 설치한 Sammie-Roto PAN을 최신 버전으로 올리는 파일입니다.

- 패치는 **누적형**이라 가장 최신 것 하나만 받으면 됩니다. (어느 버전에서든 바로 적용)
- 적용 방법: 프로그램을 종료하고, zip을 풀어서 `apply_patch.bat`을 더블클릭합니다. 자세한 내용은 [사용 설명서의 "업데이트(패치) 적용"](../README.md#업데이트패치-적용)을 보세요.
- 처음 설치하는 경우에는 패치가 필요 없습니다. 저장소를 받아 `install.bat`을 실행하면 최신 버전으로 설치됩니다.

| 파일 | 버전 | 내용 |
|---|---|---|
| `Sammie-Roto-PAN-patch-2.5.0-PAN.7.zip` | 2.5.0-PAN.7 | 헤어 디테일 보정 추가, 외곽 안정화 취소 시 원본으로 되돌아가던 문제 수정 |
