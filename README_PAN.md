# Sammie-Roto PAN 전용 빌드

[Sammie-Roto 2](https://github.com/Zarxrax/Sammie-Roto-2) (v2.5.0, GPL-3.0)를 바탕으로 만든 사내용 빌드입니다.

## 원본과 다른 점

| 기능 | 내용 |
|---|---|
| **외곽 안정화 (떨림 제거)** | 앞뒤 프레임 마스크를 옵티컬 플로우로 맞춰서 외곽 밴드만 시간축 평균을 냅니다. 세그멘테이션 탭(마스크)과 매팅 탭(매트)에 각각 있습니다. 안쪽 영역은 건드리지 않고, 원본은 백업되며 `원본 복원`으로 되돌릴 수 있습니다. |
| **원클릭 누끼** | 점만 찍고 버튼 하나로 진행합니다: 전체 트래킹 → 마스크 안정화 → 매팅 → 매트 안정화 → 내보내기 창. 매팅 모델은 GPU 메모리 12GB 이상이면 VideoMaMa, 아니면 MatAnyone2를 씁니다. |
| **안정화 전후 비교·떨림 지수** | 안정화가 끝나면 "외곽 떨림 지수 전 → 후 (%)"를 표시합니다. `누르고 있으면 안정화 전 보기` 버튼으로 같은 프레임에서 전후를 바로 비교할 수 있습니다. |
| **외곽 색 번짐 제거** | 머리카락 같은 반투명 외곽에 섞인 원래 배경색을 빼냅니다. 다른 배경에 합성할 때 예전 배경색 테두리가 남지 않습니다. 매팅 탭 체크박스로 켜고 끄며(기본 켜짐), Alpha·BGcolor 출력에만 적용되고 흑백 매트는 그대로입니다. |
| **한국어 UI** | 메뉴·버튼·툴팁·안내문을 한국어로 표시합니다. 보기·모델 선택 항목은 영어 그대로입니다. |
| **원클릭 설치** | `install.bat`을 실행하면 질문 없이 GPU 감지 → 설치 → 바탕화면 바로가기 → 모델 전체 다운로드(약 10GB)까지 진행합니다. |
| **자동 업데이트 끔** | 원본 저장소로 업데이트하면 전용 기능이 지워지므로 업데이트 확인을 껐습니다. |

## 설치 (Windows)

1. `Sammie-Roto-PAN-x.x.x.zip`의 압축을 **C:\Tools\Sammie-Roto-PAN**처럼 쓰기 권한이 있는 폴더에 풉니다. Program Files와 바탕화면 OneDrive 폴더는 피하세요.
2. `install.bat`을 더블클릭합니다. 처음 설치할 때는 패키지와 모델(약 10GB)을 받느라 수십 분 걸립니다.
3. 바탕화면의 **Sammie-Roto PAN** 아이콘으로 실행합니다.

- 권장 사양: NVIDIA GPU (VRAM 8GB 이상, VideoMaMa는 12GB 이상), 디스크 여유 30GB 이상
- 모델 다운로드가 끊기면 `install.bat`을 다시 실행한 뒤 `2) 모델 다시 받기`를 고르세요.

## 사용 순서 (머리카락 누끼)

1. `파일 → 영상 불러오기`로 영상을 엽니다. 드래그해도 됩니다.
2. 대상 위를 **좌클릭**해서 포함 점을 찍습니다. 빠진 곳은 좌클릭으로 더 찍고, 잘못 들어간 곳은 **우클릭**으로 제외합니다. 대상이 크게 바뀌는 프레임에도 점을 추가하면 정확해집니다.
3. **원클릭 누끼** 버튼을 누릅니다.
4. 내보내기 창에서 출력 종류를 고르고 내보냅니다. 출력 종류는 Matting-Matte(흑백 매트), Alpha(투명 PNG/ProRes 4444), BGcolor(그린) 중에 고르면 됩니다.

직접 단계별로 할 때:
- 세그멘테이션 탭에서 `전체 트래킹` → `마스크 외곽 안정화`
- 매팅 탭에서 모델과 내부 해상도를 고릅니다. 머리카락은 1080 이상을 권장합니다. 그다음 `매팅 실행` → `매트 외곽 안정화`

외곽 안정화 조절:
- **강도**: 기본은 마스크 70, 매트 60입니다. 떨림이 남으면 올리고, 빠른 동작에서 외곽이 늦게 따라오면 내리세요.
- **참조 프레임**: 기본은 앞뒤 2프레임입니다. 떨림이 심하면 3~4로 올리세요.
- 강도를 바꿔서 여러 번 돌려도 매번 원본에서 다시 계산합니다.
- 마스크(세그멘테이션)의 강도는 앞뒤 프레임 의견을 얼마나 따를지, 매트(매팅)의 강도는 섞는 비율입니다.

## 변경 내역

- **PAN.2**: 마스크 외곽 안정화가 기본 강도에서 거의 적용되지 않던 문제 수정, 전후 비교 버튼·떨림 지수, 외곽 색 번짐 제거, 4K 메모리 사용량 감소, 원클릭 후 내보내기 창이 매팅 출력으로 열림
